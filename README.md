# Information Retrieval System: With vs Without TF-IDF

Information Retrieval project that builds a search system over a newspaper dataset (20 Newsgroups) and evaluates retrieval quality with and without TF-IDF weighting.

## Tech Stack
Python · Scikit-learn · TF-IDF · Naive Bayes · Tkinter

## Highlights
- Text preprocessing, stop-word removal, and inverted index construction.
- Two systems: TF-IDF with cosine similarity vs a baseline without TF-IDF.
- Document classification with Multinomial Naive Bayes.
- Desktop search GUI built with Tkinter, plus a full evaluation report.

## Repository Contents
- `IR-Project/IR1.ipynb`: system with TF-IDF
- `IR-Project/IR2.ipynb`: system without TF-IDF
- `IR-Project/Evaluation.xlsx`: evaluation results
